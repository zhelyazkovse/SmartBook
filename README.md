# SmartBook 📚

SmartBook is a simple C# console-based library management system. It allows users to add, remove, list, search, and manage books, as well as save and load library collections to and from JSON files.

---

## Features

- ➕ Add books with validation for title, author, ISBN, and category.
- ➖ Remove books by ISBN.
- 📋 List all books.
- 🔍 Search books by title, author, or ISBN.
- 🔄 Toggle availability (checked out / available).
- 💾 Save books to a JSON file (as a library).
- 📂 Load a saved library.

---

## Requirements

- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download) or later
